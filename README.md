# Torimaru

Screenpresso の代替として自作した、Windows 用の無料スクリーンキャプチャ + 注釈ツール。
C# / .NET 8 / WPF 製。

**Phase 1（撮る・注釈・保存）**、**Phase 2（スクロール・OCR・色・コード）**、
**Phase 3（動画録画・音声・動画編集）** が完成している。

---

## できること

### 撮る

- グローバルホットキー 1 つで、**範囲・ウィンドウ・モニタ全体**を撮り分け
  - ドラッグ → 範囲選択
  - クリック → カーソル下のウィンドウを自動検出して撮影
  - `Space` → カーソルのあるモニタ全体 / `F` → 全モニタ / `Esc` → 中止
- **ルーペ**（既定 8 倍）で 1 ピクセル単位の位置合わせ。座標と色コードも表示
- マルチモニタ + DPI 混在環境でも座標がずれない
- **スクロールキャプチャ** — 画面に収まらないページを自動でスクロールしながら撮り、1 枚の縦長画像に合成
- **遅延キャプチャ** — 既定 5 秒後に撮影（開いたメニューを撮りたいとき用）
- **前回と同じ範囲** — 直前に撮った範囲を覚えていて、選び直さずそのまま撮れる

#### 前回と同じ範囲で撮る

同じ画面を何枚も撮るとき、毎回同じところをドラッグし直さずに済む。

| 呼び方 | 場所 |
|--------|------|
| ホットキー | `Ctrl + Shift + Q`（既定。変更可） |
| トレイメニュー | 「前回と同じ範囲でキャプチャ」（覚えている大きさが横に出る） |
| 範囲選択中 | `R` キー |

覚えるのは**最後に範囲を選んだとき**で、静止画・スクロールキャプチャ・録画のどれでも同じ。
位置は**仮想画面の座標**で `settings.json` に残るので、アプリを再起動しても引き継がれる。

モニタ構成が変わって**その範囲が今の画面に収まらなくなった場合は、黙って別の場所を撮らない**。
理由を出したうえで、いつもの範囲選択に切り替わる。

### 注釈

矢印 / 枠 / 楕円 / テキスト / **吹き出し** / **連番マーカー** / 蛍光ペン / **ぼかし** の 8 種。

- 図形は**ベクタのまま保持**され、保存時に初めて焼き込まれる
- **保存後もやり直せる** — Screenpresso では PRO 限定の「再編集」が標準で使える
- Undo / Redo、色 8 色、線の太さ 1〜20、**書体と文字の大きさ**、ズーム（Ctrl + ホイール）
- **プリセット** — よく使うツールと色・太さ・文字の組み合わせに名前を付けて、1 回押すだけで戻せる

### 切る（トリミング・中抜き）

- **トリミング** — 残したい範囲をドラッグすると、その外側を切り落とす
- **中抜き** — 縦長・横長の画像の**要らない中間部分を抜いて前後を繋ぐ**。
  長いページを 1 枚に収めたいときに使う
  - 「縦に中抜き」= 画像が縦に縮む（横帯を抜く）
  - 「横に中抜き」= 画像が横に縮む（縦帯を抜く）

拡大縮小を挟まないので**文字がぼやけない**。切ると**注釈の座標も一緒に付け替わる**ので、
矢印や吹き出しが中身とずれることはない。どちらも `Ctrl+Z` で元に戻せる。

**中抜きは、ドラッグし終えてから確定するまでの間に微調整できる。**
ドラッグした時点では切らず、抜く帯を赤く表示して待つ。

| 直し方 | 操作 |
|--------|------|
| 端を動かす | 帯の端（赤白のつまみ）をドラッグ |
| 位置ごと動かす | 帯の内側をドラッグ |
| 1 px ずつ動かす | `↑` `↓`（横に中抜きなら `←` `→`） |
| 1 px ずつ太さを変える | `Shift` + 同じキー |
| 引き直す | 帯の外からドラッグし直す |

狙いが定まったら **`Enter`**（または帯の上に出る「確定」ボタン、帯のダブルクリック）で切る。
`Esc`（または「中止」）でやめれば画像は元のまま。

### 読み取る

- **文字の抽出（OCR）** — Windows 標準エンジンを使用。追加インストールも課金も不要
  - 枠・蛍光・ぼかしのいずれかを選択していれば、**その範囲だけ**を読み取る
  - 日本語は単語ごとの空白を除いて自然に連結する（OS の出力そのままだと
    「画 面 キ ャ プ チ ャ」になるため）
- **QR コード / バーコード読み取り** — 結果はコピー・テキスト保存できる
- **画面の色を採取** — クリックした点の `#RRGGBB` をクリップボードへ

### 録る（動画）

- **画面録画（MP4 / H.264）** — 範囲・ウィンドウ・モニタを選んで録画
- **システム音声**（スピーカーに出ている音）と**マイク**を同時に録れる
- **一時停止と再開**に対応（区間を分けて録り、終了時に自動で連結する）
- 録画中は小さな操作バーが出る。**録画範囲の外に配置される**ので写り込まない
- 動画ツールで **フレームの書き出し**・**トリミング**・**結合**

> **システム音声について**
> この種のツールは「Stereo Mix」や仮想オーディオドライバに頼ることが多いが、
> 本アプリは **WASAPI のループバック取り込みを自前で実装**しているため、
> 追加のドライバやインストールは要らない。

### 保存・共有

- 撮った瞬間に自動保存（**ファイル名を聞かれない**）＋クリップボードへコピー
- ワークスペース（一覧パネル）から**他アプリへドラッグ&ドロップ**。動画も一覧に並ぶ
- PNG 1 枚で完結。配布した PNG は普通の PNG として開ける

## 使い方

### 起動

```powershell
dotnet build Torimaru.sln -c Release
.\src\Torimaru\bin\Release\net8.0-windows10.0.19041.0\Torimaru.exe
```

通知領域（タスクトレイ）に常駐する。ウィンドウは出ない。
トレイアイコンを**ダブルクリック**するとワークスペースが開く。

### ホットキー

| キー | 動作 |
|------|------|
| `PrintScreen` | 範囲・ウィンドウキャプチャ |
| `Ctrl + Shift + Q` | 前回と同じ範囲でキャプチャ |
| `Ctrl + PrintScreen` | 全画面キャプチャ |
| `Ctrl + Shift + L` | スクロールキャプチャ |
| `Ctrl + Shift + D` | 遅延キャプチャ |
| `Ctrl + Shift + C` | 画面の色を採取 |
| `Ctrl + Shift + R` | 画面録画の開始 |
| `Ctrl + Shift + W` | ワークスペース表示 |

動画ツールはトレイメニューから。

上の表は既定値。**実際に有効になったキーはトレイメニューの各項目の右側に表示される**ので、
覚えていなくても右クリックすれば分かる。一覧をまとめて見たい・コピーしたいときは
トレイメニューの **「ショートカットキー一覧…」**（コピー・テキスト保存ができる）。

#### キーを変える

トレイメニューの **「ショートカットキーの設定…」** から、この PC だけの割り当てに変えられる。
「変更」を押して使いたいキーを押すだけで、すぐ有効になる（設定ファイルを手で書く必要はない）。

- `Ctrl` / `Shift` / `Alt` / `Win` のいずれかとの組み合わせが必要
  （`PrintScreen` と `F13`〜`F24` は単独でも可）
- **他のアプリが使っているキーはその場で弾かれる**ので、設定したのに効かない状態にならない
- 他の操作と重なるキーも弾かれる
- 「既定に戻す」で元の候補に戻る

割り当ては `settings.json` の `HotKeys` に `"CaptureRegion": "Ctrl+Alt+Q"` の形で入る。

> **キーが効かない場合**
> 他のアプリや OS に先に取られていると登録に失敗する。その場合は候補キーへ自動で切り替わり、
> **実際に有効になったキー**が起動時の通知・トレイメニュー・`app.log` に出る。
> どの候補でも取れなかった項目はメニューに `（未登録）` と出る（メニューからの実行は可能）。
> 例えば `Ctrl+PrintScreen` が取られている環境では `Ctrl+Alt+PrintScreen` になる。
> Windows 11 の「PrintScreen キーで Snipping Tool を開く」は
> 「設定 → アクセシビリティ → キーボード」で解除できる。

### スクロールキャプチャの手順

1. **撮りたい先頭の位置まで、あらかじめスクロールしておく**
2. `Ctrl + Shift + L` → 対象の範囲をドラッグ（またはウィンドウをクリック）
3. 確認ダイアログで「OK」
4. マウスが範囲の中央へ移動し、自動でスクロールしながら撮影する
5. 内容が進まなくなったら末尾と判断して終了。**途中で止めるときは `Esc`**

スクロール量の検出は行ハッシュの照合で行う。右端のスクロールバーは
毎フレーム変わるため、照合対象の列から除外している。

### 画面録画の手順

1. `Ctrl + Shift + R` → 録画する範囲をドラッグ（またはウィンドウをクリック）
2. 操作バーが**録画範囲の外**に出る。そのまま録画が始まる
3. 「一時停止」で中断、「再開」で続きを録る（終了時に自動で 1 本につながる）
4. 「停止して保存」で MP4 として保存。「破棄」なら保存しない

録れる音は設定で切り替える（既定はシステム音声のみ、マイクはオフ）。

### 編集画面のショートカット

| キー | 動作 |
|------|------|
| `V` / `A` / `R` / `E` / `T` / `C` / `S` / `H` / `B` | 選択 / 矢印 / 枠 / 楕円 / 文字 / 吹き出し / 番号 / 蛍光 / ぼかし |
| `X` / `N` / `M` | トリミング / 縦に中抜き / 横に中抜き |
| `Enter` | 中抜きの帯を確定する（切る） |
| `↑` `↓` `←` `→` | 中抜きの帯を 1 px 動かす（`Shift` 併用で太さを変える） |
| `Ctrl + 1`〜`9` | プリセットを呼び出す（左から数えた番号） |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+C` / `Ctrl+S` | コピー / 上書き保存 |
| `Delete` | 選択中の図形を削除 |
| `F2` | 選択中の文字・吹き出しを書き直す |
| `Esc` | 中抜きの帯・ドラッグ中なら中止、画像を切るツール中なら選択ツールへ戻る |
| `Ctrl + ホイール` | ズーム |

置いた**文字・吹き出しは後から書き直せる**。選択ツール（`V`）で
**ダブルクリック**するか、選んで `F2` を押すと入力欄が開く。

- `Esc` で取り消せば元の文字がそのまま残る
- 吹き出しを書き直しても、**合わせた先端の向きは保たれる**（本体の大きさだけ文字に追従する）
- 文字を全部消して確定すると、その図形は削除される

### プリセット（よく使う描き方）

枠を 1 本引くたびにツール・色・太さを選び直すのが手間なので、その組み合わせに名前を付けて残せる。
ツールバーのすぐ下が**プリセットの行**で、押すとツールごと切り替わる。

| やりたいこと | 操作 |
|--------------|------|
| 呼び出す | プリセットを**クリック**、または `Ctrl` + `1`〜`9`（左から数えた番号） |
| 登録する | 今のツール・色・太さ・文字の状態で「**＋ 今の設定を登録**」→ 名前を付ける |
| 名前を変える・上書き・並べ替え・削除 | プリセットを**右クリック** |

- 並び順がそのままキーの番号になる（右クリック →「左へ移動」「右へ移動」）
- **呼び出しても、すでに置いた図形は書き換わらない**（これから描くものにだけ効く）
- 中身が同じプリセットは二重に登録できない（どれを押しても同じで区別が付かないため）
- 登録できるのは注釈のツールだけ。選択・トリミング・中抜きは登録できない

はじめて開いたときは **赤枠・赤矢印・黄マーカー・ぼかし・赤吹き出し** の 5 つが入っている。
要らなければ全部消してよく、**消した状態は次回も復活しない**。

プリセットは `settings.json` の `StylePresets` に入り、全キャプチャで共通。

### 書体と文字の大きさ

ツールバーの **文字** 欄で、書体と大きさ（px）を選ぶ。

- **選択中の文字・吹き出しにもその場で反映される**（吹き出しは本体の大きさも追従する）
- 選んだ内容は `settings.json` に残るので、**次のキャプチャでも同じ書体で書ける**
- 書体の一覧はこの PC に入っているものすべて
- 一覧の各項目はその書体自体で表示されるので、選ぶ前に見た目が分かる

#### お気に入りの書体

書体欄のとなりの **☆ / ★** ボタンで、いま選んでいる書体をお気に入りに出し入れする。
**お気に入りは一覧の先頭（区切り線の上）にまとまって出る**ので、200 件近い一覧から毎回
探さなくて済む。中身は `settings.json` の `FavoriteFonts` に残る。

| 状態 | 意味 |
|------|------|
| `☆` | お気に入りに入っていない（押すと入る） |
| `★` | お気に入りに入っている（押すと外れる） |

最初の 1 回だけ、この PC に入っている定番（Yu Gothic UI / Meiryo UI / Meiryo /
BIZ UDPGothic / MS PGothic / MS Gothic / Yu Mincho / MS PMincho / Segoe UI /
Arial / Consolas）が入った状態で始まる。そこから自由に足したり外したりしてよく、
**全部外せばその状態のまま**（勝手に定番が戻ってくることはない）。

> 書体を選べるようになる前に保存した PNG は「書体の指定なし」として読み込まれ、
> 当時と同じ見た目のまま再現される。

文字ツールは**複数行**に対応している。入力中のキーは次のとおり。

| キー | 動作 |
|------|------|
| `Enter` | 改行 |
| `Ctrl+Enter` | 確定（他の場所をクリックしても確定する） |
| `Esc` | 取り消し |

> 日本語入力中（変換中）の `Enter` は IME が受け取るので、改行にはならない。
> 変換を確定したあと、もう一度 `Enter` を押すと改行になる。

### 吹き出し

`C` または **吹き出し** ボタンを選び、置きたい場所をクリックして文字を入力する。
本体の大きさは文字に合わせて自動で決まる（改行すれば縦に伸びる）。

位置の調整は **選択ツール（`V`）** に切り替えてから。

| 操作 | 結果 |
|------|------|
| 本体をドラッグ | 吹き出しごと移動（先端も一緒に動く） |
| 先端の `○` をドラッグ | **先端だけ**動く。どの辺からしっぽが生えるかは自動で決まる |
| 先端を本体の内側へ入れる | しっぽが消える（ただの角丸ラベルになる） |

色はパレット、文字は **文字** 欄（書体・大きさ）で変わる。

#### 形と地色

ツールバーの 2 つの選択欄で切り替える。**選択中の吹き出しにもその場で反映される**ので、
置いたあとで見た目だけ変えられる（次に置く吹き出しの既定にもなる）。

| 選択欄 | 選べるもの |
|--------|-----------|
| 形 | **角丸** / **四角** / **楕円** |
| 地 | **色で塗り**（白縁＋白文字） / **白地**（色の枠＋色の文字） / **黒地**（色の枠＋白文字） |

しっぽは形に合わせて縁の位置を計算するので、楕円でも曲線の上から生える。
楕円は文字を収めるために本体が角丸より一回り大きくなる。

> 白地で**白**を選ぶと何も見えなくなるため、その場合だけ地を自動で黒へ反転する。

## 保存のしくみ

```
%USERPROFILE%\Pictures\Torimaru\
├─ 2026-10-31_18-24-39.png          配布用（注釈を焼き込み済み・普通の PNG）
└─ .originals\                       （隠しフォルダ）
   └─ 2026-10-31_18-24-39.png       注釈前のオリジナル
```

配布用 PNG の `tEXt` チャンクに注釈データ（JSON）を埋め込んでいる。
再編集時は「オリジナル画像 + 注釈データ」から組み直すので、**何度編集しても画質が劣化しない**。

> オリジナルを消してしまった場合は、焼き込み済みの画像をそのまま下地として開く
> （二重描画を避けるため、その際は注釈データを破棄する）。

### 設定

`%APPDATA%\Torimaru\settings.json`（トレイメニューから開ける）

| 項目 | 既定値 | 説明 |
|------|--------|------|
| `SaveFolder` | `Pictures\Torimaru` | 保存先 |
| `FileNamePattern` | `yyyy-MM-dd_HH-mm-ss` | ファイル名の日時書式 |
| `CaptureCursor` | `false` | マウスカーソルを写すか |
| `CopyToClipboardOnCapture` | `true` | 撮影時にクリップボードへコピー |
| `OpenEditorAfterCapture` | `true` | 撮影後に編集画面を開く |
| `LastRegion` | `null` | 最後に撮った範囲（仮想画面の座標）。「前回と同じ範囲」が使う |
| `StylePresets` | `null` | 描き方のプリセット。`null` は未作成（初回に既定の 5 つが入る） |
| `MagnifierZoom` | `8` | ルーペ倍率（2〜20） |
| `DelaySeconds` | `5` | 遅延キャプチャの待ち時間（1〜60 秒） |
| `ScrollNotches` | `3` | 1 回に送るホイールの刻み数（1〜10） |
| `ScrollSettleMs` | `260` | スクロール後に描画を待つ時間（60〜3000 ms） |
| `ScrollMaxFrames` | `60` | スクロールキャプチャの最大枚数（2〜400） |
| `OcrLanguage` | `ja` | OCR の言語タグ。空なら OS の既定 |
| `VideoFps` | `30` | 録画のフレームレート（5〜60） |

### 依存関係

| 依存 | 用途 | 種別 |
|------|------|------|
| Windows SDK 射影（`net8.0-windows10.0.19041.0`） | `Windows.Media.Ocr` による OCR | ビルド時 |
| ZXing.Net 0.16.9 | QR / バーコードの解読（純マネージド） | ビルド時 |
| ffmpeg | 動画の録画・書き出し・加工 | **実行時・別途インストール** |

Phase 1 は外部パッケージゼロだったが、OCR とコード読み取りのために上の 2 つを追加している。
どちらもネイティブ DLL を持ち込まない。

ffmpeg だけは外部プログラムとして呼び出す。無くても**静止画の機能はすべて動く**
（動画メニューを使ったときにだけ導入方法を案内する）。
音声は ffmpeg に頼らず WASAPI で直接録っているため、仮想オーディオドライバは不要。

### 設計上のポイント

- **凍結スクショ方式** — 先に全画面を 1 枚撮ってから、その静止画の上で範囲を選ぶ。
  選択中に裏の画面が動いても結果が変わらず、DPI 混在でも座標が 1:1 で一致する。
- **表示と書き出しで同じレンダラ** — `ShapeRenderer` に倍率を渡すだけ。
  「画面で見た絵」と「保存された絵」がずれない。
- **ウィンドウ列挙はオーバーレイ表示前** — 自分自身が候補に混ざらない。
- **スクロール量は行ハッシュで検出** — 画素の総当たりより桁違いに速い。
  余白行は多くのずれ量に一致してしまうため、フレーム内で**出現回数が少ない行だけ**を
  得点に数えて誤検出を防いでいる。
- **映像と音声は別々に録ってから合わせる** — 映像は ffmpeg（gdigrab）、音声は WASAPI。
  ffmpeg の最初のフレームを待ってから音声を録り始めることで頭のずれを抑えている。
  ループバックは「無音の間はデータが届かない」ため、経過時間に足りない分を
  無音で埋めて長さを合わせる。これをしないと再生が進むほど音がずれる。
- **一時停止は区間分割で実現** — ffmpeg に一時停止は無いので、区間ごとに録って
  最後に連結する。結合処理はトリム・結合機能と同じものを使い回している。
- **WPF と WinForms の名前衝突**は csproj で暗黙 using を外して解決している
  （`Point` / `Size` / `Color` / `Application` が両方の名前空間にあるため）。

## テスト

```powershell
# 純ロジックのテスト（153 件・外部依存なし）
dotnet run --project tests/Torimaru.SelfTest

# 実環境を使った結合自己診断（74 件・20 秒ほどかかる）
.\src\Torimaru\bin\Debug\net8.0-windows10.0.19041.0\Torimaru.exe --selftest
```

自己診断は実際に画面を取り込み、8 種すべての図形を焼き込み、保存・再読込・再焼き込みまで通す。
さらに OCR（英数字・日本語）、QR コードの生成と読み取り、色の採取を実機で確認し、
**一時停止をはさんだ 3 秒の録画**を実行して、映像と音声が入っていること・
2 区間が連結されていること・フレーム書き出し・トリミング・結合までを検証する。

このうち音声録音の 4 件は、**有効な再生デバイス（スピーカー・ヘッドセット）が 1 つもない環境では失敗する**（`HRESULT 0x80070490`）。

生成物は `%TEMP%\TorimaruSelfCheck\` に残るので目視でも確認できる
（`selfcheck.png` = 注釈結果、`recorded.mp4` = 録画、`frame.png` = 書き出したフレーム）。

### 自動テストで確認していないこと

対話操作そのもの（オーバーレイのドラッグ、エディタのマウス操作、
ワークスペースのドラッグ&ドロップ、実アプリに対するスクロール動作、
マイク録音、長時間録画での音ずれ）は人手での確認が必要。
